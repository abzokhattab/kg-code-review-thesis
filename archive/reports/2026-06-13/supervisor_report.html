Evaluating Context Retrieval for LLM-Based PR Reviews

Abdelrahman Khattab  ·  HPI, University of Potsdam  ·  Supervisor meeting, 13 June 2026
What this thesis is about: When an LLM writes a code review, what extra context should you give it? The thesis compares four strategies — giving the model nothing extra (Baseline), semantically similar code chunks (RAG), structured repository facts like tests and call graphs (KG), or both (Hybrid) — and measures which produces better reviews on 40 real pull requests.

How Scoring Works

Before looking at results, it helps to understand what the numbers represent.

The rubric has 25 binary criteria — each scored 0 or 1 by each of 3 judges; majority vote (≥ 2/3) gives the final score. All 25 are scored, but 13 are uninformative (ceiling, floor, or no movement across any strategy) and are excluded from the primary analysis. The 11 active criteria are the ones that actually respond to context injection.

All statistics are paired per-PR deltas: for each PR we compute (mode score − baseline score), then test whether those 40 differences are consistently positive. This controls for PR difficulty — a hard PR naturally scores low in all modes.
Cohen's d_z is the standardised effect size for paired data: mean(Δ) / sd(Δ). Rough benchmarks: 0.2 = small, 0.5 = medium, 0.8 = large. Wilcoxon p is the significance test (non-parametric, appropriate for ordinal scores). A result is considered significant at p < 0.05.

Results — Which Strategy Wins?

Which of the 25 criteria actually matter? 13 of the 25 criteria are uninformative — 3 are always 1 regardless of mode (ceiling: Q1, Q2, T1), 5 are always 0 (floor: C1, M2, P2, Q4, S2), and 5 never move by more than 0.05 across any strategy (F2, M3, Q3, R3, S1, T2). Keeping them adds noise without signal. The 11 active criteria below are the ones where context strategies actually make a difference. The 13 dropped ones are noted at the bottom.

Follow-up Experiments

Two questions were asked after the main experiment: does a richer KG do better? And does the result hold with a different LLM generator?

Experiment A — Richer KG using Joern (function-level call graph)

The main experiment's KG uses grep-based file-level evidence (which tests exist, which files depend on the changed file). Joern is an industrial call-graph tool that gives function-level precision: exact caller names, line numbers, call edges. Does more precise KG data produce a bigger effect?

Takeaway: A richer KG confirms the direction of the main result but doesn't amplify it — the model uses only ~1% of the available caller symbols. Depth of evidence alone doesn't drive the effect; it depends heavily on how the prompt is framed.

Experiment B — Different LLM generators (5 PRs, same judge panel)

The main 40-PR experiment used GPT-4o as the review generator. Does the KG benefit hold if you swap the generator? Tested on 5 representative PRs with three generators.

Generator Baseline score (/ 9 criteria) KG score (/ 9 criteria) Change Why
GPT-4o-mini (weaker) 6.00 / 115.00 / 11 −1.00 KG context hurts. The model is overwhelmed by the extra structured data and produces a worse review than without it.
GPT-4o (main experiment) 4.40 / 115.00 / 11 +0.60 KG context helps. Strong enough to use the structured data, but its baseline leaves room to improve.
Claude Sonnet 4.5 (stronger) 7.80 / 117.20 / 11 −0.60 KG context doesn't help. Claude's baseline already scores 87% — there is almost no room left to improve, and the extra context slightly distracts.
Capability sweet spot finding: KG augmentation only benefits mid-tier generators. Weaker models get distracted. Stronger models already do so well without it that there's nothing left for KG to add. This is a key nuance for the thesis: "KG helps — but only for certain generators."

Human Study (RQ3) — Ready to Launch

The LLM judge is measuring quality according to a rubric — but do human reviewers actually prefer the KG-augmented reviews? That's what RQ3 answers.

Design: 6 PRs shown side-by-side to each rater — best baseline review vs best KG-augmented review. Raters don't know which is which (blind). They rate preference and explain why.

Primary metric: Kendall's τ — measures whether the human preference ranking correlates with the LLM judge's ranking across the 6 PRs. τ = 1 means perfect agreement, τ = 0 means no correlation.

Power note: at n=6 PRs, the study can reliably detect strong agreement (τ ≥ 0.70). It's designed to validate the Joern strict result (d_z ≈ +1.07), which should be perceptible to humans if real. Smoke test: 13/13 checks pass.
