\subsection{Excluded Pull Requests and Sensitivity Check}
\label{sec:threats-builder-comparability}

Five pull requests (PRs~9, 27, 35, 36, 37), all from Grafana and all written in
Go, were excluded because the Joern CPG frontend produced graphs containing only
FILE and NAMESPACE nodes with no METHOD nodes, preventing the call-graph
extractor from building a usable evidence pack. The failure was reproduced on a
minimal Go module, confirming a frontend limitation rather than a
Grafana-specific issue. The remaining 35 pull requests constitute the evaluation
sample for Experiments~1 and~2.

As a sensitivity check, a text-heuristic file matcher was also evaluated on the
same 35 pull requests. It showed a weaker but directionally consistent effect,
supporting the conclusion that the structural mechanism is not an artefact of the
specific graph construction.
